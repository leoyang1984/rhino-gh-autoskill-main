## 1. 项目定性

这是一个**阶梯式上升的学习型项目**，以拓扑复杂度和设计推理能力为轴线持续迭代。
当前已通过 L4 验证，包括交叉多连和自然语言建模（梦露大厦几何原型已实现）。

---

## 2. 三大阶段规划

### 阶段 A：L4 → L20「建立建筑语言」
- 核心任务：建立 AI 和建筑设计之间的翻译层
- 用户需积累：输入协议（JSON Schema）、类型库（几何原型）、验证案例库（描述 + .gh 对）
- 数据形态：JSON + .gh 文件对

### 阶段 B：L20 → L50「建立设计推理」
- 核心任务：从执行描述升级到在约束下推导参数
- 用户需积累：规范规则库（Python 函数）、推理模板（JSON）、验证脚本层
- 关键转变：token 规划 + 脚本执行 + 结果验证的循环

### 阶段 C：L50 → L100「建立设计判断」
- 核心任务：多方案生成与权衡，输出对业主可读的成果
- 用户需积累：偏好编码系统、方案评分逻辑、输出渲染层

---

## 3. AI 与脚本的边界原则（核心地基，所有模块必须遵守）

**给脚本：**
- 结果确定的计算（面积、容积率、退线）
- 需要精确执行的操作（文件读写、GH 注入）
- 反复调用的验证逻辑

**给 AI：**
- 模糊自然语言的解析
- 需要权衡的策略决策
- 需要解释理由的判断

**三层架构（从 L4 到 L100 结构不变）：**
```
用户输入 → [AI 层] 解析+规划 → 输出 JSON
         → [脚本层] 执行+生成 → .gh 文件
         → [反馈层] 验证+修正 → 返回 AI 层
```

**红线：AI 不直接写数字进几何，必须经过脚本层注入，保证可审计。**
